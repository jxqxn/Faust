# Thought World original art

These files were created for Faust with OpenAI's built-in image-generation
tool on 2026-07-29. They are original production assets, not extracted from
or copied from *13 Sentinels: Aegis Rim*.

## Production prompt summary

- `school_rooftop_sunset.png`: an empty, fictional late-1980s East Asian
  school rooftop at sunset; painterly 2D side-view composition, long warm
  shadows, dense city skyline, cool violet cloud masses, no characters,
  lettering, interface, logos, or recognizable copyrighted location.
- `protagonist_idle.png`: a fictional teenage student in a dark 1980s school
  uniform, full-body three-quarter side view, semi-realistic hand-painted
  rendering, warm sunset rim light and subdued cool shadows.
- `protagonist_think.png`: the same fictional student in a restrained thinking
  pose, preserving costume, proportions, lighting, and viewpoint.
- `protagonist_walk_a.png` / `protagonist_walk_b.png`: two matching walk-cycle
  key poses for lateral movement.

The character images were generated against a chroma background and converted
to transparent PNGs. Only the final transparent production files are kept in
this directory.
