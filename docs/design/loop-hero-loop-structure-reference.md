# 《循环勇者》：自动“循环”结构的研究参照

> 状态：竞争作品机制研究入口；为“首次成型后继续运转”的结构问题建立事实边界，不宣称已经完成逐系统数值分析，也不把《循环勇者》直接登记为校园自走棋的答案。
>
> 整理日期：2026-08-14
>
> 证据入口：公开事实、市场数字和来源局限统一登记在
> [`faust-game-design-data-research.md`](../research/faust-game-design-data-research.md) 的
> `LH-*` 主张与来源中。

## 1. 新会话先读结论

《循环勇者》（Loop Hero，Four Quarters 开发、Devolver Digital 发行，2021-03-04）是回答
Faust 第 9 节焦点问题的一个**候选原型**：

> Faust 中哪一种结构应在首次成型后继续存在，并持续把后续输入转化成成长、收益与风险？

它给出的候选答案是「**循环**」：一个自动运转的环形结构，一旦建立就持续跑；玩家不直接控制
战斗，只通过“往循环里放地块”来持续塑造它，让它同时变得更危险、也更多产，并用“撤退 / 继续”
这个单一决策做收益—风险结算。

它比血流成河、酒馆战棋更接近 Faust 的“把卡牌投放到结构化槽位”这个核心语法：Loop Hero 的
“放地块进循环”几乎是槽位投放的循环化版本。因此它是最值得与麻将/酒馆战棋并列、放进第 9 节
比较的第三个候选载体。

但必须保持边界：它验证的是“自动循环 + 地块投放 + 自动结算 + 撤退决策”可以成立，**没有**
验证“具名角色关系 + 不可逆后果 + 阵容转换”如何进入同一个循环。它是单主角，不是多人阵容。

## 2. 为什么它与 Faust 高度相关

Loop Hero 的关键不是“战斗会自动播放”，而是它把玩家决策压缩成了一个持续、单一、可读的输入：

```text
一个自动运转的循环（英雄沿环形路径自动移动、自动战斗）
→ 玩家持续输入：往循环里放地块（改变地形、敌人、资源、加成）
→ 循环持续反馈：每转一圈、每放一块，同时变危险（更多/更强敌人）和变多产（更多资源/更好掉落）
→ 单一结算决策：撤退（带走资源）还是继续（冒险换更多，但可能死）
→ 跨局成长：资源带回营地，升级建筑，解锁新卡牌/职业/能力
```

这与 Faust 的核心语法直接对应：

| Faust 已复刻的语法 | Loop Hero 的循环化版本 |
| --- | --- |
| 手牌与卡牌流转（角色/机会/资源以可见、可调度对象存在） | 手牌是地块卡牌，玩家调度“往循环里放哪块” |
| 把卡牌投放到仪式槽组织一次行动 | 把地块投放到循环路径，组织一次持续运转的处境 |
| 分层结算（prior/normal/extre） | 每圈/每次遭遇的自动结算 + 撤退时的收益结算 |
| 苏丹卡倒计时与期限 | 循环的“危险随时间上升” + 撤退窗口 |

开发者自述这条链的起点不是“自动战斗 RPG”，而是「零玩家游戏」：

> “games where you don't control your hero, or anything else, directly … a little dude
> stuck in a loop while the player builds something around the loop. That was it, that
> was the whole idea.”

也就是说，Loop Hero 先把“玩家直接控制”从循环里拿掉，再问“玩家还剩下什么值得做”——答案
是“塑造这个自动循环”。这正是 Faust 当前最需要借鉴的问题定义方式，而不是某张具体地块。

## 3. 已由公开资料确认的结构

### 3.1 循环是一个自动运转的引擎

英雄从营地出发，沿环形路径自动移动、自动战斗、自动装备，直到被玩家命令撤退或在战斗中倒下。
玩家不直接控制英雄的任何即时行为。

- 起源概念是“零玩家游戏”：不直接控制英雄或任何其他东西（[`LH-RULE-001`]）。
- 玩家被开发者描述为“给冒险者当 DM（地下城主）”：在英雄前方放“刚好不会杀死他、但能让他
  变强”的挑战。

对 Faust 的价值：这证明“自动执行”可以不删除策略，而把策略迁移到“在自动结构里持续投放什么”。
但 Loop Hero 没有回答：当被投放的对象是“具名人物”而不是“地块”时，自动结构还成不成立。

### 3.2 玩家输入是“往循环里放地块”

玩家把地块卡牌放到循环路径上，永久改变本局循环的世界：地形（草地、山脉、宝库）、敌人发生器
（墓地、沼泽）、加成与建筑。放置是持续、可规划、影响后续每一圈的输入。

这几乎就是 Faust“把卡牌投放到结构化槽位组织行动”的循环化版本——槽位从“一次行动的四个位置”
变成“循环路径上的一串位置”，结算从“一次性”变成“持续运转”。

### 3.3 地块之间存在组合，放置因此成为有代价的取舍

地块“不是存在于真空中”的。开发者确认的组合实例（[`LH-RULE-002`]）：

- 放很多山脉 → 世界生成哥布林营地；
- 山脉摆对位置 → 形成山峰 → 生成会飞下来捕猎的鹰身女妖；
- 宝库有巨大资源潜力，但空宝库（四周被占满）→ 生成低等级英雄难对付的石像鬼；
- 草地最初随处可放，后来加入“放在其他地块旁 +50% 治疗”的组合规则，改变了这张卡的放置原则。

这一层是 Loop Hero 的“做牌”核心：**每块地的价值取决于它与当前循环结构的关系**，放置既是
收益也是风险。这正是麻将/自走棋“组合价值”原则在“循环”载体上的表现。

### 3.4 撤退/死亡三档结算，把收益—风险集中成一个决策

一次远征结束时保留多少资源，取决于结束方式（[`LH-RULE-003`]）：

| 结束方式 | 保留资源 |
| --- | --- |
| 战斗死亡 | 30% |
| 在非营地地块撤退 | 60% |
| 走完一圈回到营地格撤退 | 100% |
| 击败本章 Boss 后撤退 | 100%（并可选择继续） |

这个三档结算把“收益—风险”压成一个清晰、可计划的决策：**现在收手，还是再赌一圈**。它比
“赢或输”的二值结局更接近血流成河“首次和牌后继续运转”的节奏——循环不是一次结算就结束，
而是持续给玩家“收手/加注”的窗口。

### 3.5 营地 meta：死亡不惩罚实验

资源带回营地，用于升级建筑，解锁新卡牌、职业、能力、治疗药水和每局开局的免费物品
（[`LH-RULE-004`]）。开发者明确说死亡不惩罚：

> “即使英雄死了，也会带一些资源回营地升级建筑。我们不想让玩家害怕实验，或觉得自己做了
> ‘无效的游玩’。”

这解决了“不可逆后果”与“鼓励实验”之间的张力：**单局内的失败是部分可回收的，跨局始终有
正向积累**。对 Faust 而言这是关键参照——具名角色的不可逆后果若要成立，必须想清楚“哪些代价
单局回收、哪些代价跨局留存”，而不是把“死亡”一律做成挫败。

### 3.6 开发方法论：极简核心 + 加法制衡

- 极简核心只有一句：“四个 Boss、一个营地、一个无限循环的英雄。就这样。”
  （[`LH-DEV-001`]）
- 小团队刻意“限制元素数量、打磨每个元素”，避免“什么都想做”压垮开发。
- 平衡策略是**加法制衡而非删减**：村庄没有 downside、玩家到处放 → 加入“放第二个村庄会引来
  强盗”的规则来制衡，而不是移除村庄（[`LH-DEV-001`]）。

这两条对 Faust 有直接约束价值：创新期的核心循环应当先能被一句话描述；当某个占位元素过于
强势时，优先考虑“加一个制衡输入”而不是删掉它。

### 3.7 尚未由公开资料确认的内容

- 没有公开的逐局玩家行为数据（撤退时机分布、地块放置决策、死亡率、平均循环圈数）。
- 没有 A/B 或对照实验证明“循环结构”与“自动战斗”各自对留存/体验的因果贡献。
- 开发者演讲（Game Developer 的视频标题“Great design lessons and bugs from the making
  of Loop Hero”）是视频形态，文字版未取得；本文证据以 Postmortem 文字和访谈文字为准。

因此“循环结构为何让人上瘾”目前仍是媒体与玩家的解释，不是数据。Loop Hero 只是把“循环”
这个候选结构摆上了桌，不能替代 Faust 自己的原型测量。

## 4. 与 Faust 当前方向的差异

| 维度 | 《循环勇者》 | Faust 校园自走棋的未决问题 |
| --- | --- | --- |
| 行动主体 | 单主角（可选职业），无人物关系层 | 具名角色群，养成、关系、校园生活与不可逆后果 |
| 被投放对象 | 地块/地形（可重复、无个性） | 人物、机会、资源（具名、持续、有后果） |
| 循环的命运 | 地块放置后持续改变本局循环 | 仪式/行动是一次性结算，还是持续运转（未决） |
| 收益—风险 | 撤退 30%/60%/100% 三档资源结算 | 谁承担后果、哪些代价单局回收、哪些跨局留存（未决） |
| 跨局成长 | 营地建筑 + 解锁新卡牌/职业 | 具名角色的成长如何跨局持续（方向已定，结构未定） |
| 组合逻辑 | 地块组合（山脉→哥布林等） | 角色/关系的组合如何成为“做牌”而非属性叠加（未决） |
| 供给方式 | 地块卡牌从牌组逐步解锁，非随机商店 | 随机供给、保留与放弃、阵容转换仍是未决问题 |

这张表说明，《循环勇者》最值得借鉴的是**“自动循环 + 投放塑造 + 单一结算决策”这个骨架**，
而不是把它的地块、营地或职业系统直接移植进 Faust。它的骨架回答了“玩家持续在做什么”，
但没回答“具名人物如何成为这个循环里值得关心的对象”。

## 5. 对当前核心矛盾的启示与反例

Faust 当前最危险的矛盾是：

```text
人物应当长期持续、值得依恋
× 自走棋要求玩家根据供给和局势不断调整
× 项目还必须减少《苏丹的游戏》式管理负担
```

《循环勇者》给出一种可能答案：**持续运转的是一个循环，玩家持续输入的是“往循环里放什么”，
收益—风险被集中成“撤退 / 继续”一个决策。** 玩家不必在每个回合重做大量微操作，但仍持续
承担“这次投放会带来什么”的判断。

但这只是候选假说，必须主动构造反例：

1. 如果 Faust 的循环里被投放的是“地块化”的人物，具名角色可能退化成“有名字的地块”，人物意义
   只剩外观。
2. 如果“撤退 / 继续”成为唯一的收益—风险决策，“谁承担后果”的人物责任可能被抽空。
3. 如果地块组合无限膨胀，可能重蹈《苏丹的游戏》式认知超载——Loop Hero 靠“极简元素 + 加法制衡”
   控制住了，但 Faust 的具名关系层天然更重。
4. 如果循环的自动战斗缺少可读因果，玩家会把失败归因于“系统擅自行动”，而不是“我投放错了什么”。
5. 单主角的“死亡部分回收”逻辑，可能无法直接平移到“具名角色不可逆后果”上——后者要求更严格的
   跨局留存规则。

这些反例是后续原型要攻击的问题，不是用更多内容或数值掩盖的问题。

## 6. 放进第 9 节后的正确位置

Loop Hero 不应被理解为“Faust 的答案”，而应作为回答“首次成型后继续运转的结构是什么”的
**第三个候选载体**，与既有两个候选并列：

```text
做牌结构（血流成河）：首次成型后，继续摸打、反复结算既有牌型
阵容成长结构（酒馆战棋）：首次成型后，把每轮输入转化为永久属性/经济
循环结构（循环勇者）：首次成型后，持续往自动循环里投放，让循环更危险也更多产
```

三者的共同抽象仍是麻将文档第 5.4 节那一条：

```text
形成有效结构 ≠ 游戏完成
形成有效结构 = 启动一个持续接受随机输入、反复产生反馈的引擎
```

Loop Hero 的独特贡献在于：它把“输入”收敛为一种**结构化投放**（往循环里放地块），把
“反馈”收敛为一个**可计划的结算决策**（撤退/继续），因此是三个候选里最接近 Faust 现有
“把卡牌投放到结构化槽位”语法的一个。它尤其适合用来回答“玩家持续在‘做’什么”。

但它只把“循环”这个结构摆上了桌（[`LH-EXPL-001`]），并没有证明具名人物关系、不可逆后果
和阵容转换能进入同一个循环——那仍然是 Faust 自己的未决问题。

## 7. 对 Faust 的直接约束

后续方案引用《循环勇者》时，至少回答：

1. 玩家在“循环自动运转”之前，具体投放了什么？投放的是人物、人物的任务，还是人物之间的关系？
2. 自动运转之后，哪些结果能追溯到这些投放？
3. 同一具名人物的成长、关系和后果，怎样跨“投放 → 自动运转 → 撤退/继续结算”持续存在？
4. “撤退 / 继续”之外，玩家是否还有承载“人物责任”的决策？还是责任被压缩成了资源结算？
5. 地块式的组合（山脉→哥布林）在具名人物身上对应什么？是关系、羁绊，还是可被出售替换的
   属性？
6. 哪些代价单局回收（如死亡带回 30%），哪些代价跨局留存（不可逆后果），两者如何区分？

任一问题的答案若只是“把人物当地块、把撤退当结束”，则该方案尚未满足
[`autobattler-campus-direction.md`](autobattler-campus-direction.md) 第 10 节的判据。

## 8. 与主流自走棋的结构区别及对 Faust 品类归属的影响

> 本节为 2026-08-14 新增，回应“《循环勇者》与其他自走棋的区别”这一比较研究缺口。§3—§7
> 已说明 Loop Hero 的内部机制与对 Faust 的启示；本节把它放回品类坐标系，确认它和主流
> 自走棋的骨架差异，并据此校准 Faust 的品类风险。

### 8.1 品类归属：《循环勇者》不属于自走棋

主流游戏媒体在评测与预览中将《循环勇者》描述为 deck-building roguelite（地块构筑肉鸽）或
“自己玩自己的 RPG”，并未将其归入 autobattler / 自走棋品类（[`LH-GENRE-001`]）。把它与
酒馆战棋、云顶之弈、刀塔自走棋并列讨论，是 Faust 内部为回答“首次成型后继续运转的结构”
所做的抽象归类，不是市场或品类的共识。

这条边界很重要：**若 Faust 选择循环结构作为核心载体，它在品类上将更接近“自动循环肉鸽 /
增量 roguelite”，而不是“自走棋”**。这不一定是缺点（《循环勇者》商业成功，见 [`LH-MKT-001`]），
但 [`autobattler-campus-direction.md`](autobattler-campus-direction.md) 第 1 节“校园自走棋”
的产品定位需要据此重新校准。

### 8.2 九个结构维度：自走棋是“组队→互打”，循环是“造世界→看它跑”

主流自走棋（酒馆战棋 / 云顶之弈 / 刀塔自走棋）共享一个骨架：**阵容构筑 + PvP 自动战斗 +
多人淘汰**。《循环勇者》几乎在每个维度上都不同。

| 维度 | 主流自走棋 | 《循环勇者》 |
| --- | --- | --- |
| 自动化的范围 | 只自动“战斗”；购买、站位、刷新由玩家在回合间做 | 自动“整个循环”（移动+战斗+拾取+装备）；玩家在运转中只放地块 |
| 玩家输入对象 | 棋子（买/卖/升/摆）——输入是**单位** | 地块（地形/发生器/加成）——输入是**世界** |
| “阵容”概念 | 核心：反复买卖凑羁绊，阵容是做牌对象 | **无阵容**，单英雄全程不换 |
| 竞争结构 | PvP，多人同场淘汰到唯一胜者 | PvE，单人，无对手，只对循环环境 |
| 时间结构 | 离散回合，每轮一场战斗，局有终点 | 连续实时循环，无固定终点，玩家自定撤退 |
| 经济 / 供给 | 金币 + 刷新商店买棋子 | 地块手牌（每抽若干选一），无金币、无商店、无购买 |
| 局内养成 vs 跨局成长 | 几乎全在局内（星级/装备），一局结束清空，只留段位 | 双层：局内（地块/掉落装备）+ 跨局营地 meta（建筑解锁） |
| 失败 / 结算 | 输回合掉血，归零淘汰，排名=收益 | 撤退/死亡三档保留 30/60/100%（[`LH-RULE-003`]），死亡不归零 |
| “做牌”载体 | 羁绊 + 星级（阵容做牌） | 地块组合（山脉→哥布林等，[`LH-RULE-002`]）＝环境做牌 |

一句话归纳：**自走棋是“组队 → 互打”，循环是“造世界 → 看它跑”。**

### 8.3 对 Faust 的三点意义（三角权衡的代价）

把品类差异翻译成 Faust 的取舍，得到三个必须同时承担的判断：

**① 选循环路线 = 偏离“自走棋”品类**（已确认，[`LH-GENRE-001`]）。
Faust 若以循环为核心载体，产品定位会从“校园自走棋”滑向“自动循环校园养成”。循环结构本身
成立且可成功，但 [`autobattler-campus-direction.md`](autobattler-campus-direction.md) 第 1 节
“校园自走棋”这句话需要重新检验：循环结构下它还是不是“自走棋”。

**② 循环候选在“容纳具名角色”维度是三者中最弱的**（研究解释，[`LH-EXPL-001`] 的反例）。
主流自走棋的“阵容”恰好是具名角色群的天然落点——买棋子＝招募、羁绊＝关系、卖棋子＝关系
代价。《循环勇者》单主角、无关系层（[`LH-RULE-001`]），它的强项（贴现有投放语法）伴随一个
天然缺口：**没有人物群的容身之所**。这正是 Faust 最高方向（具名角色养成 + 关系 + 不可逆
后果）最看重的维度。

**③ 但循环候选解决了自走棋解决不好的问题：认知负担**（已确认）。
主流自走棋每轮大量微操（刷新、买卖、站位），与 Faust 要“减少《苏丹的游戏》式管理负担”
的目标冲突。循环把决策压成“放地块 + 撤退”，是三个候选里认知负担最低的。

三个候选在三个维度上的权衡：

| 候选载体 | 贴现有投放语法 | 容纳具名角色 | 认知负担 |
| --- | --- | --- | --- |
| 做牌（血流成河） | 中 | 中 | 中 |
| 阵容成长（酒馆战棋） | 低 | **强** | **高** |
| 循环（循环勇者） | **强** | **弱（缺口）** | **低** |

**没有任何候选在三个维度上都强。** 这正是需要在原型里验证、而不是靠文档推理决出的事。

### 8.4 本节的边界

本节是结构层面的品类与骨架比较，不是效果数据：它不证明“循环结构比自走棋更/不吸引玩家”，
也不提供 Faust 玩家负担的任何测量（[`LH-GAP-001`]、[`FAUST-DATA-001`]）。三角权衡表的
“强/中/弱”是结构性判断，不是已测参数。后续若把循环候选推进原型，必须用 [`UX-METHOD-001`]
所述指标实际测量“具名角色在循环结构里是否值得关心”，而不能用本节的推理替代。
