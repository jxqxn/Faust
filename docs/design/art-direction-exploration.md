# Faust 美术方向探索：讨论入库与验证边界

> 状态：讨论材料整理，**不是美术定案，也不覆盖现有产品方向与美术基线**。
>
> 入库日期：2026-08-28
>
> 来源：用户与网页版 ChatGPT 的 `indie_art_direction_codex_pack` 讨论包。与《苏丹的游戏》有关的三项核心来源已于 2026-09-02 重新打开核证；其他案例与包内迁移推论仍按各自证据状态处理。

## 1. 权威边界

已经确认的项目上位约束仍然是：

- [`autobattler-campus-direction.md`](autobattler-campus-direction.md)：以上海为现实参照的“魔力之都”校园、自走棋长期方向、《苏丹的游戏》卡牌流转与仪式槽位规则宿主；
- [`thought-world-visual-references.md`](thought-world-visual-references.md)：当前横版场景原型的表现与素材边界。

本次讨论包提出的“半沉水城市”“维多利亚/古典气质”“水正在溶解印刷秩序”等内容均未被用户确认为世界观或美术标准。它们只能作为未来作者探索可能重新触及的线索，不能预先写入 brief、组成候选菜单或直接指导批量生产。

## 2. 当前确认的方法

### 2.1 把风格视为生产系统

候选方向不能只回答“像什么”，还要同时回答：

- 世界与玩法信息怎样被看懂；
- 普通资产能否稳定生产；
- UI、角色、场景和 VFX 是否共享规则；
- 团队短板能否转化为一致的形式语言；
- 第 50 个乃至第 300 个资产是否仍然做得动。

这是研究建议，不是已经证明的成功公式。

### 2.2 先让作品出现，再从作品与失败中提炼规则

2026-09-02 用户确认：Faust 借鉴《苏丹的游戏》的重点，是复现其**发现风格的方法**，不是复刻最终表面。默认探索顺序修正为：

1. 给出可理解的故事原型、真实用途、情绪和制作边界；
2. 给 AI 作为视觉作者留下发明空间，不预先写死材质与构图答案；
3. 一次完成一个真实内容片段，不制作风格候选菜单；
4. 用户面对完整作品判断它是否有生命；
5. 把有价值的视觉偶然反向吸收进世界与设计；
6. 从失败中提炼下一轮要求，从成功作品中提炼可复用规则；
7. 方向产生后，才用普通资产、真实 UI、缩略图、群像和运动进行压力测试。

同题对照与评分表继续保留为后期诊断工具，不能在作者性方向出现以前充当决策程序。完整流程还原见 [`../research/sultans-game-art-direction-process.md`](../research/sultans-game-art-direction-process.md)。

### 2.3 压力与否决测试（方向出现后使用）

- 960/480/240 px 缩略图可读性；
- 灰度下的主体和层级；
- 15—20 人群像；
- 普通资产和模块复用；
- 30 秒运动中的闪烁、噪声和 UI 疲劳；
- 无 Logo 混入同类产品缩略图后的辨识；
- 一页规则交给未参与探索者后的复刻一致性。

候选若只能让英雄图成立、普通资产成本失控、真实游戏尺寸不可读或必须逐资产做独立技术补丁，应被淘汰或大幅简化。

## 3. 已淘汰方向与仍待验证的视觉命题

### 3.1 北极星候选：秩序被水溶解

> 水正在把这个文明印刷出来的秩序重新溶解。

可能生成的双语法：

- 水上/秩序：硬边、闭合线、网格、编号、印章、清晰分色；
- 水下/溶解：洇染、错版、折射、不闭合轮廓、氧化、有机重复；
- 魔法：后一套规则短暂侵入前一套规则。

待验证问题：

- “水”是否真正属于魔力之都与校园叙事，而不是讨论阶段的漂亮隐喻？
- 它能否与现代上海现实参照、D&D 转译和“魔力即资本”共存？
- 双语法能否提高状态与阵营可读性，还是只会增加纹理噪声？
- 它是否能进入卡牌流转、仪式投放和自动战斗反馈，而不只是背景装饰？

### 3.2 已淘汰的三个实验候选

| 候选 | 工作名称 | 可测试优势 | 主要风险 |
|---|---|---|---|
| A | 潮汐蚀刻 | 版画、卡牌、UI 与有限动画可能共享语言 | 线噪声与逐资产细节成本 |
| B | 珐琅登记制 | 模块化、制度感和 3D 材质区分可能较清晰 | 容易只剩装饰，角色与有机对象难统一 |
| C | 沉没博物志 | 多种族、怪物、知识与卡牌分类可能自然统一 | 日常校园和城市情感可能像博物馆陈列 |

2026-08-31 用户已将三个候选全部否决为美术方向。它们只保留材料词汇和失败经验，不得重新作为默认菜单呈现。

## 4. 降级为诊断工具的评分模型

讨论包给出的初始权重是：产能 20%，可读性/辨识度/世界统一各 15%，扩展性与玩法融合各 10%，动态表现/UI 融合/商店缩略图各 5%。

这些权重不是用户确认的产品权重，也不能用于生成或选择初始方向。只有当两个以上已经具有生命的方向需要比较生产风险时，才可恢复使用；实际评分必须同时保留原始分、评分者身份、分歧和测量证据，不能只保留加权总分。

机器可读候选记录见 [`../research/data/art-direction-exploration.json`](../research/data/art-direction-exploration.json)，完整方法库见 [`../research/data/art-direction-methodology.json`](../research/data/art-direction-methodology.json)，未来实测逐评分者原始记录使用 [`../research/data/art-direction-scorecard.csv`](../research/data/art-direction-scorecard.csv)。CSV 当前所有行均为 `not_run`，不得填入推测分数。

## 5. 尚未取得的证据

- 没有 Faust 美术候选的完成稿或引擎内同题对照；
- 没有普通 NPC、卡牌、UI、VFX 的真实工时；
- 没有缩略图、灰度、群像、运动或非作者复刻结果；
- 没有确认半沉水城市或维多利亚媒介是正式世界观；
- 讨论包列出的访谈和博物馆链接尚未逐页复核；
- 没有正式美术团队规模、技能结构和月产能基线。

因此当前正确动作是保留假说与实验结构，不是据此批量替换已有资产。

## 6. 已发生实验与教训

- **四语言候选菜单**：方法失败。它以平均化风格选项代替作者探索，没有真实项目内容，也没有能反向改变世界的视觉发明。
- **半浸水校园生活片段**：画面局部尚可，但世界转译失败。它把现代上海街景直接魔法化；用户明确要求上海只提供经过提炼的空间、气候、社会和历史关系，不能成为直接视觉模板。
- **共同根因**：AI 过早替美术写定表面答案，用户只能评价执行结果，未形成“问题空间 → 视觉发明 → 设计反向吸收”的循环。

下一次探索默认从一个真实人物、欲望和校园事件出发。Brief 优先规定要解决的问题，避免在完成图出现以前预设某种历史媒介、线条配方或上海地标替身。它是基于前两次失败得到的 Faust 工作假设，可由后续实验推翻，不是从制作组口述推导出的硬约束。
