# 单角色意志形成：当前原创方向与设计边界

> 状态：工作定义与纠偏基线，不是内容提案，也不宣告某套核心机制已经通过
>
> 更新日期：2026-07-29
>
> 适用范围：Faust 主工程中的原创机制实验、代码命名、体验评审与后续文档

## 1. 修正后的工作定义

Faust 当前探索的不是“用《苏丹的游戏》的系统扮演一个人”，而是：

> 用对象化、可持续的状态系统，模拟一名角色如何在外部压力下形成意志并采取行动。

“扮演一个人”不足以构成创新。关键问题是：角色不是一个由玩家完全支配、始终自洽的数值容器；肉体、情绪、习惯、记忆、观念、关系和处境可以共同改变他能意识到什么、倾向于做什么，以及违背自身惯性需要付出什么。

## 2. 玩家与角色不是同一个控制层

当前推荐的工作关系是：

- 玩家控制角色此刻能够调用的**注意与执行意图**；
- 玩家不是角色全部肉体和精神过程的管理员；
- 玩家应有真实决策权，但不天然全知，也不必能零成本支配角色全部状态；
- 角色的非直接控制部分首先通过感知范围、默认、阻力、时机和后效起作用，而不是只提供属性加成。

这是一项待通过机制原型验证的关系模型，不是已经锁定的数据结构。

## 3. 内在不一致不等于“脑内角色开会”

《极乐迪斯科》证明技能可以同时承担能力、感知和人格表达，但 Faust 不应把结论简化成“把人物卡换成会说话的技能卡”。

内在不一致可能表现为：

- 玩家没有意识到某个选项；
- 某种行动成为角色的默认反应；
- 身体、情绪或习惯制造行动阻力；
- 已经作出的决定形成惯性；
- 被忽略的状态在之后重新出现；
- 同一能力既提供解决方案，也制造误判或代价。

这些是机制维度。具体声音、人格、台词、技能名称和剧情归属均属于内容层，当前不决定。

## 4. 外部世界仍然必须提出问题

单角色模拟不能退化成封闭的心理活动。复刻底座最值得保留的结构之一，是外部系统持续提出角色不能简单忽略的处境。

当前方向的最小因果链是：

```text
世界提出处境
→ 角色的身体与内在结构过滤处境
→ 玩家看见角色此刻能够意识到的可能
→ 玩家形成并执行行动
→ 结果同时改变角色和世界
```

苏丹卡、事件、期限和仪式可以暂时为这条链提供占位数据，但它们的原作语义不是原创设计的默认答案。

## 5. 横版场景与思考云的正确地位

横版场景用于承载身体、位置、时间和处境；思考云用于呈现角色此刻意识到的行动可能。它们都是表现与交互层。

当前原型已经证明：

- 主工程可以从桌面切换到横版角色控制；
- 统一“思考”入口能够显示现有运行时仪式；
- 卡牌拖入、事件队列、Rite UID 和结算链可以继续复用；
- 思考结果可以保持在场景内而不遮挡卡牌栏。

当前原型尚未证明：

- 行走位置实际参与了处境计算；
- 思考界面反映的是角色有限的感知，而不是完整菜单；
- 角色具有玩家不能直接支配的惯性；
- 同一决定能够同时改写角色状态与外部世界；
- 内在不一致带来了有意义的角色扮演体验。

因此，不得用“已经做出十三机兵式画面”替代机制验收。

## 6. 当前工程边界

- 复刻规则进入维护冻结，不再默认扩充苏丹内容或 DSL。
- 机制原型可以直接进入 Faust 主工程，这是用户对 2026-07-19 旧隔离策略的明确修正。
- 继续复用 `CardInstance`、运行时 UID、Queue、Save、Rite 生命周期和分层结算。
- `MethinksEngine` 与 `drop_card_on_methinks` 是旧内容链的兼容接口；玩家可见术语统一为“思考”。
- 苏丹人物、仪式和事件只作为占位数据。它们能证明技术链，不能单独证明原创命题。
- 当前不生产人格名册、技能台词、剧情包、题材设定或思想内容。

## 7. 机制评审的唯一总问题

每项新机制首先回答：

> 它是否让玩家更明确地感到，自己正在通过一个有身体、有历史、有盲点和自身惯性的角色采取行动，而不是操纵一个换了界面的全能棋手？

如果答案只是“界面更像思考”“台词更多”“选择更有个性”或“数值更复杂”，则尚未触及当前创新方向。

## 8. 证据与阶段纪律

- 原作运行事实继续使用逆向语料库和 `$faust-clone-reference` 验证。
- 竞品机制需区分已查证事实、策划推断和待验证问题。
- 本文记录的是用户明确修正后的工作方向，不自动批准任何具体机制。
- 机制是否成立必须通过无新增内容也能运行的原型和玩家体验验收，而不能由文档自行宣布。
