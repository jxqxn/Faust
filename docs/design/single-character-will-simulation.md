# 单角色意志形成：从属机制研究与设计边界

> 状态：角色内在状态与行动主体连续性的从属研究材料；不是当前产品方向，不宣告某套核心机制已经通过
>
> 更新日期：2026-08-13
>
> 适用范围：仅在服务于 `autobattler-campus-direction.md` 的具名角色养成、关系、校园生活与持续后果时，用于 Faust 主工程中的机制实验和体验评审

> 方向层级：`autobattler-campus-direction.md` 是唯一最高产品方向。本文不能把单角色心理模拟重新确立为平行项目；具体议题顺序可以根据用户指导、新证据和原型发现调整。

## 1. 修正后的工作定义

本文研究的不是“用《苏丹的游戏》的系统扮演一个人”，而是以下从属问题：

> 用对象化、可持续的状态系统，模拟一名角色如何在外部压力下形成意志并采取行动。

“扮演一个人”不足以构成创新。关键问题是：角色不是一个由玩家完全支配、始终自洽的数值容器；肉体、情绪、习惯、记忆、观念、关系和处境可以共同改变他能意识到什么、倾向于做什么，以及违背自身惯性需要付出什么。

## 2. 玩家与角色不是同一个控制层

本研究当前推荐的工作关系是：

- 玩家控制角色此刻能够调用的**注意与执行意图**；
- 玩家不是角色全部肉体和精神过程的管理员；
- 玩家应有真实决策权，但不天然全知，也不必能零成本支配角色全部状态；
- 角色的非直接控制部分首先通过感知范围、默认、阻力、时机和后效起作用，而不是只提供属性加成。

这是一项待通过机制原型验证的关系模型，不是已经锁定的数据结构。

## 3. 内在不一致不等于“脑内角色开会”

《极乐迪斯科》证明技能可以同时承担能力、感知和人格表达，但 Faust 不应把结论简化成“把人物卡换成会说话的技能卡”。

内在不一致可能表现为：

- 玩家没有意识到某个选项；
- 某种行动成为角色的默认反应；
- 身体、情绪或习惯制造行动阻力；
- 已经作出的决定形成惯性；
- 被忽略的状态在之后重新出现；
- 同一能力既提供解决方案，也制造误判或代价。

这些是机制维度。具体声音、人格、台词、技能名称和剧情归属均属于内容层，当前不决定。

## 4. 外部世界仍然必须提出问题

单角色模拟不能退化成封闭的心理活动。复刻底座最值得保留的结构之一，是外部系统持续提出角色不能简单忽略的处境。

本研究的最小因果链是：

```text
世界提出处境
→ 角色的身体与内在结构过滤处境
→ 玩家看见角色此刻能够意识到的可能
→ 玩家形成并执行行动
→ 结果同时改变角色和世界
```

苏丹卡、事件、期限和仪式可以暂时为这条链提供占位数据，但它们的原作语义不是原创设计的默认答案。

## 5. 横版场景的正确地位

横版场景用于承载身体、位置、时间和处境，是表现与交互层。场景表现参考
《大骑士物语》的图板棋子结构与《圣兽之王》的手绘奇幻画面；"思考云/思考模式"
（十三机兵式语法）已从场景中移除，角色感知与行动可能的问题不再用该语法呈现，
机制未定。

当前原型已经证明：

- 主工程可以从桌面切换到横版角色控制；
- 卡牌拖入、事件队列、Rite UID 和结算链可以继续复用；
- 角色位置能够限制近距交谈和场景出口，地点、出生点与位置可随存档恢复；
- NPC 对话能够逐句进入统一 Queue，并以依附当前说话者的无框短句呈现；连续对白复用同一场景标签，不切换到独立对话页面。

当前原型尚未证明：

- 行走位置除了近距交互之外，实际参与了规则层的处境计算；
- 玩家可见的行动可能如何受角色状态限制（原思考云形态已移除，机制未定）；
- 角色具有玩家不能直接支配的惯性；
- 同一决定能够同时改写角色状态与外部世界；
- 内在不一致带来了有意义的角色扮演体验。

因此，不得用"已经做出《圣兽之王》式画面"替代机制验收。

## 6. 当前工程边界

- 复刻规则进入维护冻结，不再默认扩充苏丹内容或 DSL。
- 机制原型可以直接进入 Faust 主工程，这是用户对 2026-07-19 旧隔离策略的明确修正。
- 继续复用 `CardInstance`、运行时 UID、Queue、Save、Rite 生命周期和分层结算。
- `MethinksEngine` 与 `drop_card_on_methinks` 是旧内容链的兼容接口；玩家可见术语统一为“思考”。
- 苏丹人物、仪式和事件只作为占位数据。它们能证明技术链，不能单独证明原创命题。
- 当前不生产人格名册、技能台词、剧情包、题材设定或思想内容。

## 7. 机制评审的唯一总问题

每项新机制首先回答：

> 它是否让玩家更明确地感到，自己正在通过一个有身体、有历史、有盲点和自身惯性的角色采取行动，而不是操纵一个换了界面的全能棋手？

如果答案只是“界面更像思考”“台词更多”“选择更有个性”或“数值更复杂”，则尚未触及当前创新方向。

## 8. 证据与阶段纪律

- 原作运行事实继续使用逆向语料库和 `$faust-clone-reference` 验证。
- 竞品机制需区分已查证事实、策划推断和待验证问题。
- 本文记录的是用户明确修正后的工作方向，不自动批准任何具体机制。
- 机制是否成立必须通过无新增内容也能运行的原型和玩家体验验收，而不能由文档自行宣布。

## 9. 已完成克隆内容的第一轮整体映射

本轮不导入尚未复刻的《苏丹的游戏》内容，也不新增剧情、人物、人格或
“内在声音”。迁移对象仅限 Faust 当前已经验收的克隆内容。

迁移的共同规则是：

> 阿尔图始终是玩家唯一直接控制的行动主体。其他人物、物品和苏丹卡
> 仍保留原有定义与结算，但在操作层分别表示阿尔图能够卷入的人、
> 能够调用的事物和必须应对的外部压力。

| 已验收内容 | 原克隆操作 | 单角色方向中的含义 |
|---|---|---|
| 治理家业 | 把贵族、辅佐者、装潢和道具放入仪式 | 阿尔图决定把家业托付给谁、调用什么条件；人物的原有应答和结算保持不变 |
| 思考（兼容 `俺寻思`） | 把任意卡牌交给即时处理链 | 阿尔图把注意集中到一个人物、物品或苏丹命令上；被拖入对象不是新的玩家角色，也不是预设人格 |
| 书店营业 | 选择本人或他人前往，投入金钱或道具 | 阿尔图决定亲自行动、请求谁代办、为此投入什么；书店老板与偶遇人物仍是外部人物 |
| 淘书三变体 | 随机生成地点变体，再选择同行者与费用 | 一个外部机会进入阿尔图可意识到的行动范围；地点、同行者和费用继续决定结果 |
| 上朝 → 权力的游戏 | 苏丹、谗言、贵族、苏丹卡和派遣者进入常驻仪式 | 苏丹及朝廷仍是外部权力；玩家决定阿尔图如何亲自应对、让相关人物卷入或冒险使用苏丹卡 |
| 卡牌实例与装备 | 人物和物品拥有独立 UID、标签与装备 | 它们继续记录具体的人和物如何被过往行动改变，而不是变成一次性技能图标 |
| Queue、跨日与存档 | 事件、选择、延迟和仪式状态持续存在 | 阿尔图的行动发生在连续时间中；离开界面或读档不会改变“谁正在行动” |

### 9.1 运行时边界

- `player_actor_uid` 指向本局阿尔图的 `CardInstance`。
- 仪式无论放入谁，规则上下文中的玩家行动主体仍是阿尔图。
- 其他人物卡是“相关人物”：放入槽位表示邀请、委托、依靠、对抗或卷入，
  不表示玩家切换成了这个人物。
- 物品卡是“可用事物”：放入槽位表示在行动中使用。
- 苏丹卡是“外部压力”：放入槽位表示选择一种应对方式。
- 思考链额外记录 `focus_card_uid`，明确区分“正在思考谁/什么”和
  “玩家正在扮演谁”。
- Queue 和 v5 存档保留 `player_actor_uid`；旧 v5 存档缺少该字段时，
  从带有“主角”标签的现有卡牌实例恢复。

这套映射只建立单一行动主体和现有内容的操作含义，不提前决定身体、
情绪、记忆、习惯、观念或内在声音将采用什么机制。
