## 核心思路（2026-09-24 用户与助手对齐，持续修订）

用户要求从头对齐设计思路后，经逐问确认写入。原话与纠错过程见[原话表](evidence-and-decisions.md#2-已恢复的关键原话)。本节是主题与体验方向，**不批准任何具体机制**；与下方旧版“30 秒入口”“产品边界”冲突时，以本节为准，旧版中未被本节触及的约束暂时保留，待后续逐项重审。

1. **核心命题**：客观、绝对、被确认为正确的版本不存在；只有被剪辑过的版本，但它们并非毫无意义。主题参照《再见绘梨》的剪辑、春物的“真物”、《浮士德》在误认中说出“真美啊，请为我停留”。用户称其为“核心中的核心”，想探讨这一现代性问题引发的一系列现象。
2. **符号化、欲望与幻想**（2026-10-07修订，用户评价“更正确了”，仍可继续纠正）：物质性客观，但不存在规定其意义的精神性权威。一件事只要动用理性分析，就必然被抽象成指数，即符号化；不存在未剪辑的版本，因此符号化是双刃。核心隐喻：魔法=Index/符号化（讲座摘要“Index是资本的当代范式”；D&D法师为稀少的智力职业与准备施法者；法术如规定范围、耗蓝、伤害、冷却的SOP）。欲望指向实在界的创伤，符号化法术只能给出替代物——浮士德向梅菲斯特求符号化法术，却欲望实在界，故始终不得满足；最终满足发生在他想象的宏伟工程中，对应《再见绘梨》“加一点幻想”的剪辑。规则描述与实际结算天然不完全一致（“以实际结算为准”）。旧表述“实在界=够不到的物质事实”已被用户指为浅薄，不再使用。
3. **玩家位置**：主要是亲身经历者；先像浮士德一样活在自己的版本中，事后看见另一个版本——但那也只是一面之词（如梅菲斯特），不构成官方真相。
4. **乐趣来源**：回溯性建构——研究冷门build、多视角可解释的剧情。每名玩家实际玩到哪些部分、如何解读，是设计师无法决定的“偏斜”。最需避免：过度引导；剧情的官方唯一解释。强度榜、全信息卡面次之。
5. **苏丹底座的价值**：与杀戮尖塔、影之诗把结算写在卡面不同，苏丹人物卡投入事件后如何结算不写死，能指与所指未闭合；希望在玩家学会之后仍尽可能保持打开，同时考虑现实成本。

## 已确认的产品边界

| 决定 | 含义 | 不包含的承诺 |
|---|---|---|
| 魔力之都校园 | D&D 为主，对现代上海与资本关系作概念转译 | 不强制现实地标、水城、维多利亚画风 |
| 基于现有机制创新 | 卡牌、结构化槽位、实例状态和后果承载主要玩法 | 不另建脱节的校园菜单或自走棋演示 |
| 人物进入自动对局 | 同一具名人物跨养成、关系、行动与后果持续存在 | 不强制卖人、永久死亡、24 个心理代理或固定玩家视角 |
| 降低管理负担 | 改造检索、重复操作和当前决策面 | 不把少点击等同低负荷，不删除人物历史凑少手牌 |
| AI 主创、用户教练 | 交付具体可判断成果，用户指导修正 | 不一次倾倒巨型方案，不把沉默当批准 |

## 仍然开放

玩家是学生、教师或其他主体；人物如何获得、保留与离场；阵容如何重构；战斗粒度和可解释性；时间结构；成型后是否持续运转；永久后果的作用层级；胜败终局；最终画风和资产规模，均没有最终答案。

日历、昼夜、苏丹式压力卡、强制期限、随机商店、持续仪式、Loop Hero 式循环都属候选。旧文的“必须先定压力引擎”“一年日历是硬约束”“当前核心问题固定为成型后运转”不再有效。
