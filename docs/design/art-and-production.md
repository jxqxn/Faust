# 美术与创作生产：阶段成果

2026-09-14。产品边界见[下一阶段契约](next-stage-handoff.md)，数据证据见[研究总报告](../research/faust-game-design-data-research.md)，原始方案与方法包见[归档清单](../archive/innovation-20260914/manifest.json)。

## 1. 当前真正确定与未确定的事

已确认的世界观输入：以 D&D 为主要词汇，将现代上海作概念转译；法师学派对应学科，守序邪恶魔鬼的契约对应资本关系，“魔力之都”与魔力/资本承载校园生活。它不是要求画地标、旗袍或水淹校园。

**尚未确定最终画风。** 潮汐蚀刻、珐琅登记制、沉没博物志三案在 2026-08-31 被否决；维多利亚、水城、秩序溶解等旧北极星词汇没有因此获批。四种风格菜单和半淹校园的失败，需要保存为方法教训，而非下次继续精修的默认方向。

2026-09-02 的明确推进方式是：先拿出一个真实完整作品供用户判断，设计吸收作品里的有效发明，再总结可传递规则。不是先让用户在抽象标签或评分表中选画风。

## 2. 苏丹制作方法能支持什么

既有访谈记录了“大体需求—美术独立发挥—拿出完成图—设计反向包装”的实例；异常配饰曾引发争论后保留。静态桌游质感与女术士/卡盒的不同画风及 Live2D，有明确的叙事表达意图。

这支持给作者发明空间、用完成内容做判断。不能据此编造每张图固定三天、固定主美最终拍板、没有动画师、先有 Style Bible 或严格固定 SOP。演讲里的“能动的人离职”“连续开三枪”含幽默和比喻，不按字面转成岗位与迭代次数。

壁画、雕塑、风化黑线是对成品的描述；公开材料没有证明它们如何从最初 brief 推导出来。限制解释了部分表现取舍，不会逻辑必然地产生某一种画风。所谓“复现方法”是检验发现过程与解题质量，不是再次生成苏丹表面风格。

来源保留：[触乐](https://www.chuapp.com/article/290268.html)、[IGN JP 访谈中文转录](https://www.taptap.cn/moment/809350638671497907)、[制作人演讲报道](https://club.gamersky.com/activity/1521791)。最近一次资料核证记录是 2026-09-02，本轮未联网复查。

## 3. 从完整作品到可生产风格

一次探索的输入只需足够具体：画的是谁、处在什么关系或冲突、在游戏里如何出现、玩家必须看懂什么。画面本身应给出作者判断；不要用一张充满相互矛盾标签的 moodboard 代替作品。

用户判断后记录“保留什么、排除什么、为什么”，区分个人不喜欢、角色不成立、玩法不清晰和生产不可持续。不要把一句“不喜欢”改写成对某类媒介的永久禁令。

方向出现以后，才验证延展性：普通人物与关键人物、同一人的不同用途、事件画面、卡面与缩略图、UI 控件是否仍属于同一世界。960/480/240 像素、六角色、15–20 人同屏、30 秒识别等旧方法包参数都是测试建议，不是已测阈值或必须先完成的考试。

风格语法应从成功作品提取：轮廓、形体、明暗、色彩、材料、构图、空间、文字、动效例外及禁用情况；同时提供正反例和修正方法。它的目的在于让普通资产可重复生产，不是把探索提前封死。

## 4. 生产约束与应撤回的伪约束

旧记录显示用户负责判断/筛选、配合生成式 AI 和 AI 编辑，零外包；周人时没有实测。手绘与动画能力记录只是当时资源盘点，应在真正制作时确认有没有变化。不能从“没有精细手修”推出永远只能大色块，或从“暂未反对”推出用户已批准所有动画方案。

原作约 1300 张卡、历史 29 个视图脚本、3840×2160 设计画布是参考体量或当时工程状态，**不是原创首版资产配额**。横版场景+桌面的“双呈现模式”也不是最终必选架构。原作资产为复刻参照，不等于原创商业发行的资产许可。

建议把图中文字留给引擎渲染，以便清晰、本地化和改稿；用参考图、角色身份特征与一致性检查控制重复生成。静态为主、代码动效、分层木偶等都是成本方案；在测过制作和维护成本前，不把某一种称为已验证最优管线。

生产记录至少保存：输入与版本、生成/修改次数、有效工时、失败原因、可复用比例、同角色一致性、UI 可读性、导入验证和最终去留。旧评分 CSV 的 not_run 保持“未执行”；权重只是诊断建议，不计算伪总分或用分数替用户审美。

## 5. 表现参考与旧原型去留

大骑士物语提供绘制场景与棋子式定位、有限步数和出征表现参考；不因此引入其四人、AP 或在线战争。圣兽之王同时提供人物美术与条件式战斗参考，不能只登记为视觉资料。《This Is the Police》提供派遣资源到事件的参考；警员并非字面上的匿名单位。

thought world 的前中后景、雾、视差、角色居中属于历史表现探索。小丑牌式卡牌动效、横版场景、独立校园菜单在复刻恢复时被要求隔离。此处保存可借鉴经验，不说明它们当前已经获准重新进入正式循环。

## 6. 创作流程如何服务下一阶段

用户提出 AI 主创、用户教练：AI 应形成具体完整判断，让用户通过作品和可玩内容指导；这不表示无限授权发布，也不允许用大方案轰炸用户。用户后续明确要求一点点讨论，因此一次推进一个核心问题。

旧生产路线“痛点→体验命题→压力原型→时间结构→对象→容器→内容→DSL”保留为可选方法，不能把压力和期限变成所有项目的前置门禁。更稳妥的通用顺序是：具体人物处境 → 一项可观察改动 → 可玩闭环 → 反例与真实体验 → 从反复出现的需求提炼通用能力。

内容制作卡可以记录：人物与关系、行动入口、可投入对象、判断依据、选择与不行动后果、状态回写、后续读取、保存恢复和玩家复述。需要几条垂直链由验证范围决定；“3–5 条”是旧建议而非已定计划。DSH/Cordis 插件 Recipe 属于历史工具经验，调用契约要先在当前运行时核对，不能把旧 API 当仍可用的工具。

## 7. 跨作品方法材料保留什么

旧美术包还积累了多种不同路径，不能只保留苏丹一例。下表是既有材料的研究摘要，本轮未重新核证这些外部案例；具体工期、帧数、百分比和“唯一作者意图”不提升为事实。

| 材料 | 候选启示 | 当前使用边界 |
|---|---|---|
| Splatoon：墨水原型、兔子到鱿鱼 | 角色形式回应玩法行为，失败帮助明确需求 | 不证明所有项目都要玩法先行，也不把旧转述的 70+/6 个月作为本项目工期 |
| 荒野之息：同场景放入旧作视觉比较 | 用引擎内真实内容判断风格是否妨碍物理直觉 | “一分钟拍板”即便属实也不等于准备只需一分钟 |
| TF2：写实到可识别职业轮廓 | 用实际辨识失败提出团队、职业、武器的视觉层级 | 不是所有美术需求只能后置 |
| Hollow Knight：少人团队的简化与可扩展画法 | 日常资产吞吐量与一致性共同决定可生产性 | 不把“不能做 3D”等二手概括当完整团队能力事实 |
| Cuphead：坚持媒介与动画选择 | 作者可以有意识承担更高成本 | 旧帧数和“慢 80%”未在本轮复核，不据此估算 Faust |
| GRIS：艺术先于并影响玩法 | 美术也可以主导体验探索 | 不是所有成功作品都从规则 brief 推导视觉 |
| Darkest Dungeon：个人风格规则外显 | 将作者判断写成可复用正反例 | “黑边/无眼睛完全由系统推导”等强因果仍待核证 |

方法包中的实验卡、决定日志、Style Grammar、普通资产压力测试、成本表都完整归档。重新使用时先填实际任务和未知项，不能把旧模板中的默认数字当用户要求，也不能为了复用模板而恢复已否决方向。
