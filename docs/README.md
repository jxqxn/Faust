源码、运行配置、资产、测试输入、依赖许可及应用会话元数据保留各自职责，不当作文档垃圾删除。隐藏目录的旧计划已经纳入验收正文，早期截图和会话元数据纳入资料清单。原始语料库保持只读；Git历史用于追溯已整合的旧正文。
