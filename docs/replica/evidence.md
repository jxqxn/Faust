# 证据资料与再生成

[打开可搜索证据册](evidence-browser.html)；[查看逐文件哈希与章节归属](evidence-manifest.json)。

所有截图、JSON、CSV、反汇编、日志、旧诊断原型及隐藏目录附件都已登记用途与解释边界。文件保留原路径是为了保持测试/导出工具的稳定输入，不是未整合材料；旧平行Markdown已删除。当前状态只见[验收正文](verification.md)。

## 证据类型

| 类型 | 文件数 | 使用方式 |
|---|---:|---|
| 历史诊断工具或原型 | 3 | 不是当前产品契约或正式运行入口 |
| 历史运行日志 | 6 | 只证明该次运行；当前结果见verification正文 |
| 原作结构或表现测量数据 | 51 | 具体字段证据；静态作者值与运行测量分别解释 |
| 应用会话元数据 | 4 | 标题和创建时间仅用于来源定位；不构成设计决定或执行计划 |
| 截图或图像证据 | 465 | 按文件记录的状态使用；不单凭截图认定过程等价 |
| 扫描候选或数据表 | 5 | 候选/统计不等于已验证问题或已通过 |
| 早期克隆诊断截图 | 1 | 1152×648旧克隆窗口，控件错位且含AudioManager缺失报错；不是原作截图、当前UI目标或通过证据 |
| 状态审计与验证数据 | 4 | 范围以配套方法与输入记录为准 |
| 着色器反汇编证据 | 25 | 用于具体程序/常量核验，不推定完整渲染等价 |
| 研究来源与整合索引 | 3 | 按来源日期、主张等级和决定状态使用 |

## 维护

运行 tools/build_documentation_views.py 更新离线阅读器及清单，再运行 tools/check_workspace_documentation.py。导出布局仍写入原JSON，并更新统一layout-data.json；不再生成旧Markdown。新资料没有登记或退役旧正文复现时，校验必须失败。

原始创新ZIP已从工作区删除，仅通过843f0100的Git对象追溯；清单和校验器可离线核验。仓库外的双端运行材料由[外部证据登记](external-evidence.json)统一承载路径、哈希与用途，不复制原作完整存档进项目。
