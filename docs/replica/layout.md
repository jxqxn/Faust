# 原作布局数据册

完整原作RectTransform、布局组、Canvas和图像引用集中使用JSON证据；旧逐文件Markdown表已删除，避免数据双份漂移。下列每个表均有来源记录、原文件哈希和原JSON路径。参数是静态作者值，不能替代运行时ContentSizeFitter、文本测量和输入验收。

阅读时先选页面/Prefab，再查层级路径和字段。表现层当前结论见[presentation](presentation.md)，可交互检索见[布局浏览器](layout-browser.html)。
